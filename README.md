Репозиторий содержит курсовой проект «Сравнительный анализ алгоритмов рекомендательных систем для персонализированного подбора мультидоменного контента и создание рекомендательной системы в Telegram-боте».

В рамках работы реализован Telegram-бот, предоставляющий пользователю персональные рекомендации фильмов, книг и курсов на основе его действий внутри системы. Проект объединяет разработку пользовательского интерфейса бота и реализацию гибридной рекомендательной системы.

В рекомендательном модуле используется комбинированный подход, включающий методы коллаборативной фильтрации, контентной фильтрации и обработку неявной обратной связи пользователей. Система собирает и анализирует пользовательские взаимодействия, формирует персонализированные рекомендации и поддерживает сценарий «холодного старта».

В проекте реализованы генерация синтетического датасета, хранение пользовательских взаимодействий, вычисление сходства пользователей и объектов, а также интеграция рекомендательного алгоритма с Telegram Bot API.

Проект разработан на Python с использованием библиотек PyTelegramBotAPI, Pandas и Scikit-learn и предназначен для демонстрации полного цикла создания рекомендательной системы — от обработки данных и построения алгоритмов до интеграции с пользовательским приложением.
