## О проекте

Разработан Telegram-бот, реализующий **гибридную рекомендательную систему** для подбора мультидоменного контента (фильмы, книги и онлайн-курсы). 

Бот собирает неявную обратную связь от пользователей и формирует персонализированные рекомендации в реальном времени.

## Основной функционал

- Просмотр каталога объектов разных доменов
- Оценка контента тремя типами взаимодействий:  
  ` Просмотр` • ` Лайк` • ` Избранное`
- Персонализированные рекомендации
- Fallback-механизм для новых пользователей (cold start)
- Поддержка множественных пользователей одновременно

## Рекомендательная система

В проекте реализован **гибридный подход**, сочетающий:

- **Content-Based Filtering** — TF-IDF векторизация описаний + косинусное сходство
- **User-based Collaborative Filtering** — поиск похожих пользователей
- **Popularity-Based** — учёт общей популярности объектов

Такое сочетание позволяет эффективно работать с мультидоменным контентом и хорошо справляться с проблемой холодного старта.
